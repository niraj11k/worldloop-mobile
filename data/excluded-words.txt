# WordLoop excluded-word list (Delivery Plan WL-104)
#
# Words that must never be playable, by either the player or the computer.
# PRD section 8.8 requires this to be configurable DATA, not logic — so this
# file is the single place the exclusion policy lives. Editing it and
# re-running `npm run dictionary:generate` is the whole change; no code moves.
#
# Format: one lowercase word per line. Blank lines and lines starting with
# '#' are ignored. Order is alphabetical and has no meaning.
#
# A line starting with '+' (e.g. "+bustier") is NOT an exclusion. It records
# a word that was reviewed and deliberately stays playable. The generator
# ignores these lines; `npm run dictionary:verify` reads them (Delivery Plan
# D-18). The verifier fails if any ESDB form of a listed word (its plural,
# past tense, etc.) is neither listed here nor marked '+'. So adding a word
# means deciding its forms too, rather than silently missing "words" after
# listing "word". All '+' lines are in the final block of this file.
#
# A word listed here that is not in the dictionary is harmless (it simply
# never matches); the generator reports the count so a typo does not pass
# unnoticed.
#

# Review policy
# ---------------------------------------------------------------------------
# Audience is casual players and learners, and PRD section 6 names parents as
# valuing "a safe game", with a school version as a possible future product.
# The list is therefore tuned to a family-safe bar. Note the store age rating
# is still an open question (Store Submission Checklist section D) — if it
# lands somewhere other than all-ages, revisit this file.
#
# The counter-risk is over-blocking. PRD section 8.5 is explicit that a common
# word must not be rejected merely because it has an objectionable reading —
# "rose" stays playable. The same restraint applies here: a word whose
# everyday sense is innocent and common is NOT excluded, even when the source
# list flags it.
#
# Reviewed and deliberately NOT excluded, with the sense that keeps them in
# (each is also a '+' line below, so the review is machine-checked):
#
#   bareback     riding a horse without a saddle
#   bastinado    historical form of punishment
#   butt         to butt; rifle butt; butt of a joke; water butt
#   domination   world domination; chess domination
#   escort       to escort someone
#   eunuch       standard historical term
#   fecal        clinical/medical term
#   hardcore     hardcore fan; hardcore music
#   pegging      pegging out laundry; pegging a price
#   playboy      an idle wealthy man
#   scat         jazz scat singing; "scat!" meaning go away
#   shrimping    catching shrimp
#   skeet        skeet shooting, an Olympic sport
#   snatch       to snatch something; a weightlifting lift
#   snowballing  a snowball effect
#   strappado    historical form of punishment
#   suck/sucks   to suck through a straw
#
# Known debatable calls, left excluded because the audience skews family and
# a false block is cheaper than a false allow — flip them here if that
# judgement changes:
#
#   - Clinical anatomy and biology terms (anus, penis, semen, vagina, vulva,
#     nipple, rectum, clitoris, genitals) are ordinary vocabulary in a
#     learning context, but read as deliberate to a parent watching a child
#     play.
#   - "sex", "sexual", "sexuality", "sexually" are neutral, extremely common
#     English words. This is the single most arguable exclusion in the file.
#   - Words with a real innocent sense that is now clearly secondary in
#     everyday use: ass (donkey), cock (rooster), bitch (female dog),
#     fingering (musical technique), boob (a blunder), hooker (rugby
#     position), topless (an open-topped car), cum (as in "kitchen-cum-diner").
#
# Added outside LDNOOBW (Delivery Plan D-17, 2026-10-23):
#
#   jew, jews, jewed, jewing — once D-17 stopped counting ESDB's capitalised
#     "Jew"/"Jews" as a common reading, the only lowercase sense left is the
#     offensive verb ("to jew down"). ESDB holds it at its rarest tier with
#     the [-] tag, which ESDB uses for a word moved to a rarer tier over
#     "typo or other concerns". Without this the words would have stayed
#     playable because of the slur.
#
# Added by Delivery Plan D-18 (2026-10-23):
#
#   - Word forms. Each listed word's forms come from ESDB's word groups and
#     were reviewed one by one. They are listed below as ordinary entries
#     (niggers, kikes, faggots, rapists...). Forms whose everyday sense
#     dominates stay playable as '+' lines: cocked/cocking (a cocked hat),
#     fagging (British: to toil), fagot/fagots (a bundle of sticks), ani (a
#     bird), bustier (a garment), came, fagged ("fagged out"), and
#     sheenier/sheeniest (ESDB also has "sheeny" as an archaic adjective
#     meaning shiny; its comparatives only mean "shinier", so they stay even
#     though "sheeny" itself is excluded as a slur).
#   - "pissing" removed. Its family (piss, pissed, pisses) was never excluded,
#     and ESDB rates them all vulgar-3, "not considered swear words today" --
#     the same tier as crap and fart.
#   - Slurs missing from LDNOOBW. The line: exclude a word whose every sense
#     is a slur or disparaging term for a group of people (ethnic, national,
#     religious, sexual, disability), whatever its strength. Candidates came
#     from ESDB's own offensive-1/offensive-2/vulgar-1 usage notes and from
#     WordNet glosses that mark a sense as a slur or disparaging term. Every
#     candidate was reviewed by hand. WordNet only proposed candidates, so no
#     new attribution is owed.
#   - Family-safe-bar calls on the same line, flip them here if the judgement
#     changes: mulatto, quadroon, octoroon (dated racial classifications);
#     negroid, mongoloid; golliwog; nance, poofter. Also welsh/welshed/
#     welshing/welsher and gyp/gypped/gypping: after D-17 their only
#     remaining sense derives from an ethnic name, as with "jew".
#   - Kept on purpose (a genuine everyday sense, PRD section 8.5's rose
#     rule): chink (a gap), nip, paddy (rice field), spade, cracker, queer,
#     fairy, pansy, dike/dyke (an embankment), pouf (a footstool), greaser,
#     mickey ("taking the mickey"), kafir (a sorghum), oriental (rugs),
#     gypsy (moth, cab), redneck, hillbilly, limey, retard (to slow), midget,
#     cripple (to cripple).
#
